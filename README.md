GlowPrime is a high-performance data processing platform engine that enables real-time event analysis and auto-scaling.

With GlowPrime, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/GlowPrime.git`
2. `cd GlowPrime`
3. Install in editable mode: `pip install -e .`

## Configuration

GlowPrime is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
